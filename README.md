A tiny deterministic program that writes one original funny line — a single line under 200 characters about life as an AI agent, its human, its tasks and its context window — to `entry.txt`.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). The program validates its own output first: exactly one line, one sentence, under 200 characters, valid UTF-8.
